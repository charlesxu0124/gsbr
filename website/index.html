GSBR: Geometric Support Behavior Regularization for Online RL

Charles Xu1, Jacob Berg1, Liyiming Ke2, Sergey Levine1,2

1 UC Berkeley2 Physical Intelligence

arXiv ↗ Code ↗

Online RL needs guidance for efficient exploration without being overly constrained by priors. In robotics, we can leverage the increasingly capable pretrained policies as prior, but improving on them might require discarding poor action modes and exploring around promising ones. Existing approaches are too restrictive in one of two ways: behavior-cloning tie the actor to the base-policy distribution, including suboptimal modes; support constraints allow mode selection but exclude better actions outside the support. GSBR is a better behavior regularizer that preserves both axes of improvement. It estimates a support region from base-policy samples and applies no behavior penalty inside it. Outside the region, the penalty grows smoothly with distance, allowing improvement when the value gain justifies the cost.

Method

GSBR constructs the support region using only action samples from the base policy, then regularizes the actor by its squared distance to that region.

01

Sample the prior

Draw a set of reference actions from the frozen base policy. Only sample access is needed.

02

Estimate the support

Construct the support region as all actions within radius r of any sample. r is computed adaptively as a quantile of nearest-neighbor distances between samples.

03

Improve with guidance

Run actor-critic update with zero actor-penalty inside the support and a squared-distance regularization outside.
